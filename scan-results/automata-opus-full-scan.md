**Message:** The script header claims 'non-destructive connectivity checks,' but line 106 executes `vault kv get -field=password` which actually retrieves the plaintext password for status.redhat.com from Vault. This is misleading — a truly non-destructive check would verify access (e.g., `vault kv metadata get` or `vault token lookup`) without fetching the actual secret value. Also update the script comment/header to accurately describe what the checks do.
